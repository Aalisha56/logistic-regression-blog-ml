# Logistic Regression — Machine Learning Field Notes

A standalone, responsive educational blog about Logistic Regression.

## Included
- `index.html` — complete article, navigation, dataset preview, references
- `style.css` — responsive editorial layout and topic-specific color palette
- `script.js` — accessible mobile section navigation
- `customer_churn_teaching_data.csv` — 120 rows of synthetic teaching data
- `assets/` — exactly five labelled visualizations used by the article

## Open locally
Extract this ZIP, then double-click `index.html`. No build process or package installation is required. The Google Fonts import is optional; system-font fallbacks are included.

## Dataset provenance
The CSV is synthetic and generated specifically for this teaching website. It should not be interpreted as real-world evidence. Any figure explicitly described as illustrative is a conceptual teaching figure, not model evaluation results.

## Deployment
Create a **new** Netlify site for this topic, extract the ZIP, and drag the extracted folder (the folder containing `index.html`) into Netlify's manual deploy area. Verify that the page loads, navigate to the dataset section, download the CSV, and open each figure.
